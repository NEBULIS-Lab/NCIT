# Open-based NCIT implementation

The user selected Open by Cruip and requested the original Demo1 to replace the recorded video. The business deck's cover background photograph must not appear on the website.

The implementation retains Open's visual structure and animation components, maps the existing bilingual NCIT content into that structure, and builds a separate same-origin Demo1 application. Original assembly controllers, planning, scene layout and fixed control clock are preserved. Only Demo1 is selectable in the embedded version.

Acceptance: template provenance is explicit; Chinese/English works across the site and demo; the simulation loads with four physical arms, starts, pauses and resets; fullscreen and camera controls work; deployment includes all required models; the prohibited cover photo and old video are absent from published files.
